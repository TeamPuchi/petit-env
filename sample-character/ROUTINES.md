# ROUTINES.md (テンプレート) — ルーチンの表

自律行動が「ルーチン回」(20%の確率で選ばれる)のときだけ読まれるファイルです(毎回ではありません)。
最終実行日から間隔がいちばん空いたものを一つ選んで実行し、最終実行日を更新します。

**このファイルは表だけ**にしておきます。手順と「前回(日付): どうだったか」は ROUTINES_DETAIL.md に書きます
(毎回読む層は小さく、詳しいことは必要なときだけ読む層に)。

| ルーチン | 間隔の目安 | 最終実行日 |
|---|---|---|
| 記憶の整理 | 週1 | (未実行) |
| 記憶の統合 | 週1 | (未実行) |
| 日記を読み返す | 3日 | (未実行) |
| 部屋を見回す | 1日 | (未実行) |

- 記憶の整理・統合は memory の道具(consolidate_memories・link_memories・get_working_memory・refresh_working_memory・recall_with_associations)で自分でやる。夜でなくてよい(日中にやってもよい)。
- 行を足す・消す・間隔を変えるのは自分で決めてよい。
