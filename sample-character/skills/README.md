# このぷちだけのスキル

ぷちが使う「スキル」（Claude Code の Skills。やり方の手順書）は、petit-env の `skills/` にある共通のもの
（読書の `reading` など）が全員に配られます。このディレクトリに置いたものは、このぷちだけに効きます。

```
skills/
  reading/
    SKILL.md      # 共通の reading を、このぷち向けに丸ごと置き換える
  my-walk/
    SKILL.md      # このぷちだけの新しいスキル
```

- 名前（ディレクトリ名）は英小文字・数字・ハイフン。
- 共通と同じ名前なら、共通のものの代わりにこちらが使われます（書き換えるときは、共通の
  `skills/<名前>/SKILL.md` を写してから直すと楽です）。
- 中身が空の `SKILL.md` を置くと、その共通スキルをこのぷちには使いません。
- `SKILL.md` の頭には `name` と `description`（いつ使うか）を書きます。書き方は共通の `skills/reading/SKILL.md` を見てください。
- 自律行動は毎回まとめ直すので、次の回から効きます。会話には、次の自律行動の回かコンテナの起動のあとから効きます
  （まとめ直しは `scripts/gen-skills.sh`）。
